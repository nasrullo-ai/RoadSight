Reproduce the sample predictions

On a machine with Python 3.10+ and an NVIDIA GPU:

pip install -r requirements.txt
python run_submission.py --videos data/samples --out predictions_samples.json
python evaluate.py --pred predictions_samples.json --validate-only

Or without installing anything but Docker:

docker build -t roadsight .
docker run --gpus all --network none -v $PWD/data/samples:/videos -v $PWD/outputs:/out roadsight
